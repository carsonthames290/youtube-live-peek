# Live Stream Scout

Make a website that can run through GitHub on a cloudflare subdomain that lets you search YouTube channels and watch their live streams. Just live streams though. Make it not show any streams until you look up their profile

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://youtube-live-peek.lovable.app
